Telegram 为什么突然不能用了？

当 Telegram 突然连不上——消息发不出、图片视频加载不了、或者一直转圈——通常不是你的手机问题，而是你的运营商或国家在封锁或限速 Telegram。这常发生在抗议、选举、考试期间，或长期审查之下。

解决办法是 Telegram 代理：位于其他国家的一台服务器，替你转发 Telegram 流量，让封锁看不到它。Telegram 有自己的代理类型，叫 MTProto，人们会免费公开分享这些代理。

问题在于：公共列表几小时内就会失效，所以你找到的大多数代理早已失效。Nimku Proxy 解决了这一点——它测试每个代理，只显示此刻可用的。

第 1 步 — 安装应用

  1. 从发布页下载 NimkuProxy.apk。
  2. 打开下载的文件。安卓会请求安装许可——点 设置 → 允许来自此来源 → 安装。
  3. 小米、华为和三星需要额外几步——见安装指南。

第 2 步 — 获取可用代理

有两种方式，第二种在其他一切都被封时依然有效：

A. 让应用自动查找

打开应用，选择扫描深度并开始。它从几十个公共来源收集代理并逐个实测。适合大多数人。

B. 从 Telegram 机器人获取文件（如果 GitHub 被封）

在某些地区，应用无法访问来源，因为 GitHub 本身被封。而 Telegram 通常仍可用——打开 @Nimkubot，点 获取代理列表，它会发给你一个文件。点该文件 → 打开方式 → Nimku Proxy，应用就会检测这个列表。

第 3 步 — 连接

  1. 应用显示可用代理，最快的排在最上面。
  2. 点一个。Telegram 打开并询问是否启用代理。
  3. 确认——Telegram 就恢复正常了。

每个代理都在你自己的网络上测试，所以显示为可用的对你确实可用。若某个失效了，只需打开应用换一个。

安全吗？

Nimku Proxy 是开源的——任何人都能查看代码——且无广告、无跟踪、无 Google 或 Firebase 服务。它不碰你的 Telegram 账号或消息，只把一个代理交给 Telegram 应用。每个版本都可在 VirusTotal 上检查，并可通过签名证书验证。详情见主页。

一句实话：公共代理由陌生人运营，所以别把代理当作隐私工具——你的 Telegram 聊天在你和 Telegram 之间仍是加密的，但请用它来访问 Telegram，而不是隐藏你的身份。

常见问题

代理和 VPN 一样吗？

不一样。VPN 转发手机全部流量；MTProto 代理只被 Telegram 使用，其他应用不受影响。它更轻量，专为 Telegram 设计。

需要付费吗？

不需要。应用和代理完全免费——无订阅、无账号、无广告。

代理失效了怎么办？

很正常。打开应用重新扫描，或从 @Nimkubot 获取新文件，换一个即可。列表每小时更新。

iPhone 能用吗？

应用仅支持安卓。在 iPhone 上你仍可用 @Nimkubot 获取代理链接，手动添加到 Telegram。
