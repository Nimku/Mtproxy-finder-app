## این برنامه به چه دردی می‌خورد؟

در برخی کشورها تلگرام فیلتر است، کند شده، یا اصلاً وصل نمی‌شود. راه معمول عبور
از این وضعیت، استفاده از **پروکسی** است: کامپیوتری دیگر، جایی در کشوری دیگر،
که ترافیک تلگرام شما را به جای شما رد می‌کند.

تلگرام نوع پروکسی مخصوص خودش را دارد که به آن **MTProto** می‌گویند. مردم این
پروکسی‌ها را به‌صورت عمومی و رایگان در فهرست‌ها و کانال‌ها منتشر می‌کنند.

مشکل اینجاست که **این فهرست‌ها خیلی سریع از کار می‌افتند.** پروکسی‌ای که صبح
کار می‌کرد، تا شب مرده است — یا شلوغ می‌شود، یا مسدود، یا صاحبش خاموشش می‌کند.
بیشتر آدرس‌های هر فهرست عمومی، همان لحظه‌ای که پیدایشان می‌کنید از کار
افتاده‌اند. امتحان کردن یکی‌یکی آن‌ها با دست، کُند و خسته‌کننده است.

**Nimku Proxy این کار را برای شما انجام می‌دهد.** برنامه آدرس پروکسی‌ها را از
فهرست‌های عمومی متعدد جمع می‌کند، تک‌تکشان را آزمایش می‌کند، و فقط آن‌هایی را
نشان می‌دهد که **همین حالا** کار می‌کنند — سریع‌ترین‌ها در بالا. بعد روی یکی
می‌زنید و وصل می‌شوید.

این برنامه **کاملاً رایگان** است. بدون پرداخت، بدون اشتراک، بدون حساب کاربری،
بدون ثبت‌نام و بدون تبلیغات.

## این برنامه چه چیزی **نیست**

بهتر است شفاف باشد که چه چیزی نصب می‌کنید:

- **این VPN نیست.** ترافیک گوشی شما را از جایی رد نمی‌کند. فقط آدرس پروکسی
  پیدا می‌کند و آدرسی که انتخاب کرده‌اید را به تلگرام می‌دهد. تنها تلگرام از
  آن استفاده می‌کند؛ مرورگر و بقیهٔ برنامه‌ها دست‌نخورده می‌مانند.
- **به‌جای شما به تلگرام وصل نمی‌شود.** به حساب کاربری، پیام‌ها و شمارهٔ تلفن
  شما کاری ندارد و هرگز از شما نمی‌خواهد وارد حسابی شوید.
- **هیچ اطلاعاتی از شما جمع نمی‌کند.** نه حساب کاربری، نه آنالیتیکس، نه ردیاب،
  نه تبلیغات. بخش [حریم خصوصی](#حریم-خصوصی) را ببینید.

## چطور کار می‌کند

```
  ۱. جمع‌آوری        ۲. آزمایش           ۳. نمایش            ۴. اتصال
  ───────────        ─────────           ────────            ────────
  آدرس پروکسی از     به هر آدرس واقعاً    فقط آدرس‌های سالم   تلگرام باز
  فهرست‌های       →  وصل می‌شویم      →  فهرست می‌شوند،   →  می‌شود و از
  عمومی متعدد                            سریع‌ترین در بالا    شما می‌پرسد
```

مهم‌ترین بخش، مرحلهٔ ۲ است. فهرست‌های عمومی معمولاً پروکسی‌ها را «تأییدشده»
علامت می‌زنند، اما آن علامت مربوط به زمان ساخته‌شدن فهرست است — شاید چند روز
پیش. Nimku Proxy به این ادعاها اعتماد نمی‌کند و خودش، همین حالا، از روی گوشی و
شبکهٔ شما، یک دست‌دادن واقعی MTProto با هر آدرس انجام می‌دهد. پروکسی‌ای که
جواب ندهد، اصلاً در نتایج شما ظاهر نمی‌شود.

این جزئیات از آنچه به نظر می‌رسد مهم‌تر است: یک پروکسی فقط **از شبکهٔ شما**
سالم است یا نیست. پروکسی‌ای که در یک کشور خوب کار می‌کند ممکن است در کشوری
دیگر مسدود باشد. چون آزمایش روی دستگاه خودتان اجرا می‌شود، نتیجه دقیقاً برای
شما درست است.

## نصب برنامه

اندروید تا زمانی که خودتان اجازه ندهید، نصب برنامه از بیرون Google Play را
ممنوع می‌کند و بعضی سازنده‌ها مرحله‌های اضافه هم می‌گذارند. این برای هر
برنامه‌ای خارج از Play Store عادی است و مخصوص این برنامه نیست.

### اندروید معمولی (۸.۰ و بالاتر)

۱. فایل `NimkuProxy.apk` را از
[آخرین نسخه](https://github.com/nimku/mtproxy-finder-app/releases/latest)
دانلود کنید.

۲. فایل دانلودشده را باز کنید. اندروید می‌گوید مرورگر (یا تلگرام، یا فایل
منیجر) اجازهٔ نصب برنامه ندارد.

۳. روی **تنظیمات** بزنید ← گزینهٔ **اجازه از این منبع** را روشن کنید ← برگردید
← **نصب**.

این اجازه فقط برای همان یک برنامه است؛ با اجازه دادن به مرورگر، به چیز دیگری
اجازه نداده‌اید.

### شیائومی / ردمی / پوکو (MIUI، HyperOS)

بیشترین مرحلهٔ اضافه اینجاست و معمولاً همین‌جاست که مردم بی‌خیال می‌شوند:

- تنظیمات ← **حفاظت از حریم خصوصی** ← **مجوزهای ویژه** ← **نصب برنامه‌های
  ناشناس** ← مرورگرتان را انتخاب کنید ← روشن کنید.
- MIUI اسکن خودش را اجرا می‌کند و یک هشدار تمام‌صفحهٔ ترسناک نشان می‌دهد.
  گزینهٔ **به‌هرحال نصب کن** را بزنید.
- اگر باز هم نصب نشد: تنظیمات ← حفاظت از حریم خصوصی ← **امنیت پیشرفته**
  (Enhanced security) را خاموش کنید. تا وقتی روشن است، MIUI بی‌صدا جلوی نصب را
  می‌گیرد. بعد از نصب می‌توانید دوباره روشنش کنید.
- بعضی نسخه‌های MIUI برای کامل کردن نصب، ورود به حساب Mi و اتصال اینترنت
  می‌خواهند. این شرط MIUI است، نه این برنامه.

### هواوی / آنر (EMUI، HarmonyOS)

- تنظیمات ← **امنیت** ← **تنظیمات بیشتر** ← **نصب برنامه از منابع خارجی** ←
  به مرورگر یا فایل منیجر اجازه بدهید.
- اگر Pure Mode روشن باشد، هر چیزی غیر از AppGallery را رد می‌کند:
  تنظیمات ← امنیت ← **تنظیمات بیشتر** ← **Pure Mode** ← خاموش کنید.

### سامسونگ (One UI)

- تنظیمات ← **برنامه‌ها** ← روی مرورگر بزنید ← **نصب برنامه‌های ناشناس** ←
  اجازه بدهید.
- در One UI 6.0 و بالاتر، **Auto Blocker** کلاً جلوی نصب جانبی را می‌گیرد:
  تنظیمات ← **امنیت و حریم خصوصی** ← **Auto Blocker** ← خاموش کنید.

### اگر گوشی اصلاً اجازه نداد

بعضی گوشی‌های قفل‌شدهٔ اپراتوری و دستگاه‌های سازمانی واقعاً اجازهٔ نصب جانبی
نمی‌دهند. در این حالت از طریق کامپیوتر و کابل USB نصب کنید:

```bash
adb install NimkuProxy.apk
```

## طرز استفاده

### اولین اجرا

۱. برنامه را باز کنید. چیزی برای تنظیم کردن نیست: نه ورود، نه کلید، نه
ثبت‌نام.

۲. **پروفایل شبکه** را انتخاب کنید — خودکار، Wi-Fi یا LTE. اگر دلیل خاصی
ندارید روی **خودکار** بگذارید؛ خودش تنظیمات آزمایش را با اتصال شما هماهنگ
می‌کند.

۳. **عمق اسکن** را انتخاب کنید:

- **سریع** — یک بررسی سریع، برای استفادهٔ روزمره کافی است. از همین شروع کنید.
- **متعادل** — آدرس‌های بیشتر، هنوز نسبتاً سریع.
- **کامل** — همهٔ آنچه جمع شده را بررسی می‌کند، تا ۱۵٬۰۰۰ آدرس. کند اما کامل.
  وقتی اسکن سریع چیزی پیدا نمی‌کند از این استفاده کنید.
- **سفارشی** — تنظیمات دلخواه خودتان.

۴. شروع کنید. نتایج **همان حین اسکن** ظاهر می‌شوند — لازم نیست تا آخرش صبر
کنید. سریع‌ترین پروکسی‌ها به بالا می‌آیند.

### اتصال به یک پروکسی

۱. روی یکی از پروکسی‌های فهرست بزنید.

۲. تلگرام باز می‌شود و می‌پرسد که این پروکسی فعال شود یا نه.

۳. تأیید کنید. حالا تلگرام از آن عبور می‌کند.

اگر بعداً از کار افتاد — که پروکسی‌ها دائماً از کار می‌افتند — کافی است Nimku
Proxy را باز کنید، دوباره اسکن بزنید و یکی دیگر انتخاب کنید.

### چند نکتهٔ کاربردی

- **علاقه‌مندی‌ها** — پروکسی‌هایی که برایتان خوب کار می‌کنند را ستاره بزنید.
  برنامه می‌تواند در پس‌زمینه بی‌سروصدا بررسی‌شان کند و وقتی یکی از کار افتاد
  خبرتان کند.
- **تاریخچه و آمار** — ببینید کدام منابع واقعاً روی شبکهٔ شما پروکسی سالم
  می‌دهند و کدام‌ها وقت تلف‌کردن‌اند.
- **کد QR** — یک پروکسی را به‌صورت QR نشان دهید تا به کسی که کنارتان است
  بدهید، یا از روی عکس بخوانید.
- **خروجی گرفتن از فهرست** — پروکسی‌های سالمتان را در یک فایل ذخیره کنید.
- **افزودن منبع دلخواه** — اگر فهرستی می‌شناسید که در برنامه نیست، آدرس HTTPS
  آن را در تنظیمات اضافه کنید.
- **ظاهر** — تم، رنگ، گردی گوشه‌ها، اندازهٔ متن و زبان رابط کاربری.

## اگر GitHub در کشور شما باز نمی‌شود

برنامه معمولاً فهرست پروکسی‌ها را از GitHub می‌گیرد و چند سرویس آینه هم به
عنوان پشتیبان دارد. در بعضی مناطق خود GitHub در دسترس نیست — و این حتی بین
شهرها و بین اپراتورهای مختلف یک کشور فرق می‌کند. اگر اسکن اصلاً هیچ چیزی پیدا
نکرد، به احتمال زیاد دلیلش همین است: برنامه اصلاً نمی‌تواند به فهرست‌ها برسد.

**یک راه دوم هست که اصلاً به GitHub نیاز ندارد:**

۱. ربات ما را در تلگرام باز کنید و فهرست فعلی پروکسی‌ها را بخواهید. ربات یک
فایل ساده برایتان می‌فرستد.

۲. همان‌جا داخل تلگرام روی فایل بزنید.

۳. گزینهٔ **باز کردن با ← Nimku Proxy** را انتخاب کنید (در بعضی گوشی‌ها
«اشتراک‌گذاری» یا «Open in» نوشته شده است).

۴. برنامه فهرست را می‌خواند و دقیقاً مثل یک اسکن عادی بررسی‌اش می‌کند.

همچنین می‌توانید پیامی حاوی لینک پروکسی را فوروارد و با Nimku Proxy
به‌اشتراک بگذارید، یا هر فهرستی را در یک فایل `.txt` ذخیره کنید و از داخل
برنامه با **بررسی فایل** بازش کنید.

معمولاً وقتی GitHub در دسترس نیست، تلگرام هنوز کار می‌کند — دقیقاً به همین
دلیل در این حالت فهرست از راه تلگرام می‌آید.

## آیا نصبش امن است؟

نباید یک فایل APK ناشناس را فقط به این دلیل که کسی گفته نصب کنید، و لازم هم
نیست به ما اعتماد کنید. چند راه برای بررسی هست، از ساده‌ترین تا محکم‌ترین.

### خودتان اسکنش کنید

فایل APK را در سرویسی مثل VirusTotal بالا بگذارید یا با هر آنتی‌ویروسی که به
آن اعتماد دارید بررسی کنید. همراه هر نسخه یک فایل `.sha256` هم منتشر می‌شود؛
می‌توانید همان مقدار را در جستجوی VirusTotal بگذارید تا مستقیم گزارش فایل را
پیدا کنید.

توجه کنید که آنتی‌ویروس‌ها گاهی برنامه‌های پروکسی و شبکه را بر اساس حدس و
الگو علامت می‌زنند. اگر یکی دو موتور چیزی گزارش کنند و بقیه هیچ، معمولاً
هشدار اشتباه (false positive) است، نه یک یافتهٔ واقعی.

### مطمئن شوید فایل دستکاری نشده

در هر نسخه، کنار فایل APK یک فایل `.sha256` هست. مقایسه کنید:

```bash
sha256sum NimkuProxy-v2.0.0.apk
```

اگر مقدار یکی بود، نسخهٔ شما بایت‌به‌بایت همان چیزی است که منتشر شده.

### بررسی کنید چه کسی امضایش کرده

این محکم‌ترین بررسی است و مخصوصاً برای به‌روزرسانی‌ها مفید است. همهٔ نسخه‌ها
با یک کلید یکسان امضا می‌شوند، پس یک نسخهٔ دستکاری‌شده یا بسته‌بندی‌مجدد
نمی‌تواند این مقدار را داشته باشد:

```bash
apksigner verify --print-certs NimkuProxy-v2.0.0.apk
```

نتیجهٔ مورد انتظار:

```
Signer #1 certificate SHA-256 digest: d205a5af6051d2d29b418c6094aa8da760e5fbb05f128bf031d9890f138fad96
```

صاحب گواهی: `CN=Nimku Proxy, O=Nimku, C=US`. به‌روزرسان داخلی خود برنامه هم
پیش از نصب هر به‌روزرسانی دقیقاً همین بررسی را انجام می‌دهد، بنابراین تعویض
بی‌سروصدای کلید ممکن نیست.

### خودتان بسازید و مقایسه کنید

قطعی‌ترین پاسخ به «واقعاً داخل این فایل چیست» این است که آن را از روی کد
منبع همین مخزن بسازید و مقایسه کنید:

```bash
git clone https://github.com/nimku/mtproxy-finder-app
cd mtproxy-finder-app
git checkout v2.0.0
./gradlew --no-daemon assembleRelease
```

بدون کلید امضا، خروجی یک APK **بدون امضا** در این مسیر است:
`app/build/outputs/apk/release/app-release-unsigned.apk`. کد کامپایل‌شدهٔ آن
را با نسخهٔ منتشرشده مقایسه کنید، بدون فایل‌های امضا که طبیعتاً نمی‌توانند
یکسان باشند:

```bash
mkdir -p built published
unzip -q -o app/build/outputs/apk/release/app-release-unsigned.apk -d built
unzip -q -o NimkuProxy-v2.0.0.apk -d published
sha256sum built/classes*.dex published/classes*.dex
diff -r -x 'META-INF*' built published
```

مقایسهٔ معنادار همان `classes*.dex` است — کد واقعی برنامه همان است.

برای رسیدن به همان ساخت، به همان ابزارهای CI نیاز دارید: **JDK 17** (نسخهٔ
Temurin)، **Android SDK 35**، **Gradle 8.9** (همان wrapper داخل مخزن)،
**AGP 8.7.3**، **Kotlin 2.0.21**. نسخهٔ متفاوت JDK یا افزونه، ساختی متفاوت اما
به همان اندازه معتبر می‌دهد.

صادقانه دربارهٔ محدودیت‌ها: ابزارهای ساخت اندروید تضمین نمی‌کنند که خروجی روی
ماشین‌های مختلف بایت‌به‌بایت یکسان باشد، بنابراین تفاوت‌های کوچک در ترتیب
فایل‌ها یا زمان‌ها طبیعی است و نشانهٔ دستکاری نیست. آنچه به‌صورت رمزنگاری‌شده
منشأ یک ساخت را ثابت می‌کند، همان بررسی گواهی امضا در بالاست.

## حریم خصوصی

- بدون تبلیغات، بدون آنالیتیکس، بدون ردیاب، و بدون سرویس‌های Google و Firebase
- بدون حساب کاربری، بدون ورود، بدون پرداخت — هیچ اطلاعاتی از شما جمع یا ارسال
  نمی‌شود
- برنامه فقط با فهرست‌های عمومی پروکسی و با تلگرام نصب‌شدهٔ خودتان ارتباط
  می‌گیرد. با هیچ چیز دیگری.
- نتایج اسکن و علاقه‌مندی‌ها روی گوشی خودتان می‌مانند
- منابعی که خودتان اضافه می‌کنید باید HTTPS باشند و پیش از استفاده اعتبارسنجی
  می‌شوند تا یک آدرس مخرب نتواند برنامه را وادار به کاوش شبکهٔ خانگی شما کند
- به‌روزرسانی‌ها پیش از نصب از نظر نسخه، نام بسته، گواهی امضا و SHA-256 بررسی
  می‌شوند

یک هشدار صادقانه: **پروکسی‌های عمومی را افراد ناشناس اداره می‌کنند.** گردانندهٔ
یک پروکسی می‌بیند که شما وصل شده‌اید و چه حجمی ترافیک می‌فرستید. گفتگوهای
تلگرام شما بین شما و تلگرام رمزگذاری‌شده می‌ماند و چت‌های محرمانه هم
سرتاسر-رمزگذاری‌شده باقی می‌مانند، اما پروکسی ابزار ناشناس‌ماندن نیست و
جایگزین رمزگذاری نمی‌شود. از آن برای رسیدن به تلگرام هنگام فیلتر بودن استفاده
کنید، نه برای پنهان کردن هویتتان.

## برای کسانی که قبلاً پول پرداخت کرده‌اند

نسخه‌های پیش از ۲.۰ اشتراک پولی می‌خواستند. آن به‌کلی حذف شده — نسخهٔ ۲.۰ و
بالاتر اصلاً هیچ مجوزی را بررسی نمی‌کند و چیزی نمی‌پرسد. اگر هنوز روی نسخهٔ
قدیمی هستید، برای آن حالت رایگان برای همه فعال شده و حتی اگر هرگز به‌روزرسانی
نکنید هم کار می‌کند.

## پروکسی‌ها از کجا می‌آیند

برنامه از فهرست‌های عمومی پروکسی استفاده می‌کند که چند پروژهٔ متن‌باز
نگهداری‌شان می‌کنند؛ همه در
[`sources_manifest.json`](sources_manifest.json) فهرست شده‌اند. موارد تکراری
حذف می‌شوند و بعد خود برنامه تک‌تک آدرس‌ها را بررسی می‌کند — به برچسب
«تأییدشده»‌ی خود فهرست‌ها به‌تنهایی اعتماد نمی‌شود.

## برای توسعه‌دهندگان

### ساخت

به JDK 17 و Android SDK 35 نیاز دارد.

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

ساختار کد:

```text
core/       ثابت‌ها و ابزارهای مشترک
domain/     مدل‌ها، پارسر، منابع، تجمیع‌کننده
data/       شبکه، Room، DataStore، خروجی
ui/         Jetpack Compose + Material 3
updater/    دانلود و بررسی به‌روزرسانی
work/       بررسی‌های پس‌زمینه و کارهای به‌روزرسانی
```

### محتویات مخزن

| مسیر | چیست |
|---|---|
| `app/` | برنامهٔ اندروید (Kotlin، Jetpack Compose، Material 3) |
| `sources_manifest.json` | فهرست منابع عمومی پروکسی |
| `.github/workflows/mirror-proxy-feeds.yml` | کار زمان‌بندی‌شده برای آینه کردن منابع در `proxy-feeds/` |
| `update_manifest.json` | اطلاعات پشتیبان به‌روزرسانی برای مناطقی که GitHub API مسدود است |
| `license/status.json` | باقی‌مانده — فقط برای کارکردن نصب‌های پیش از ۲.۰ نگه داشته شده |
| `exteragram/` | افزونهٔ اختیاری برای کلاینت exteraGram |

### امضای نسخهٔ انتشار

`assembleRelease` تنها زمانی امضا می‌شود که متغیرهای محیطی
`RELEASE_KEYSTORE_PATH`، `RELEASE_KEYSTORE_PASSWORD`، `RELEASE_KEY_ALIAS` و
`RELEASE_KEY_PASSWORD` تنظیم شده باشند (به `app/build.gradle.kts` نگاه کنید) —
بدون آن‌ها ساخت انجام می‌شود ولی APK بدون امضا خواهد بود. در CI فایل
`.github/workflows/release.yml` سکرت‌های متناظر GitHub Actions را می‌خواند
(`RELEASE_KEYSTORE_BASE64` به‌جای `_PATH`). خود فایل کلید هرگز در این مخزن
قرار نمی‌گیرد.

### ارسال به VirusTotal

ورک‌فلوی انتشار می‌تواند هر APK را به‌صورت خودکار در VirusTotal بارگذاری کند و
لینک گزارش را در توضیحات نسخه بگذارد. برای این کار به سکرت مخزن
`VIRUSTOTAL_API_KEY` نیاز است (کلید رایگان VirusTotal کافی است). بدون این
سکرت، نسخه باز هم منتشر می‌شود و لینک گزارش هم چاپ می‌شود — فقط بارگذاری
انجام نمی‌شود، پس گزارش تنها زمانی وجود خواهد داشت که کسی خودش فایل را اسکن
کند.
